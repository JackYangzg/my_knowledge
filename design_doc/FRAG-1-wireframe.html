6. 4 状态 ↔ 按钮可见性矩阵

状态 底部按钮组合 缺口卡 完整度横条 目标卡 状态 badge
NEED_REVIEW 📥 重新分析 — 其它 — 显示 (按 priority 排序,top 3 折叠) 显示 (< 100% 时为蓝) 显示 待完善
DISTILL_READY — 重新分析 — ✨ 开始提炼 显示"✅ 0 缺口" 显示 (100%,蓝色) 显示 可提炼
RECOMMEND_READY — 重新分析 — 📦 归档 显示 wiki_synthesis 卡片(已生成) 显示 (100%,绿色) 显示 可归档
ARCHIVED ⭐ 标星 / 已标星 📤 分享图片 不显示 (chain 已稳定) 显示 (归档时间) 显示 (border-left 变绿) 已归档
和"4 tab 文案"的映射: 全部 = 所有 chain; 待完善 = status='NEED_REVIEW'; 可提炼 = status='DISTILL_READY'; 归档 = status IN ('RECOMMEND_READY', 'ARCHIVED') —— 2 个状态合并到 1 个 tab (用户原话"归档"tab 没细分"已生成未确认"vs"已确认",v1 简化)
