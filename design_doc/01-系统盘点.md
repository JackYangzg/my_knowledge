## 2. Theme 层（设计 token 应有的家）

### 2.1 颜色（Color.kt）

```kotlin
val Purple80 = Color(0xFFD0BCFF)        // 仅作为 M3 fallback
val PurpleGrey80 = Color(0xFFCCC2DC)     // 仅作为 M3 fallback
val Pink80 = Color(0xFFEFB8C8)           // 仅作为 M3 fallback
val Purple40 = Color(0xFF6650a4)         // 仅作为 M3 fallback
val PurpleGrey40 = Color(0xFF625b71)     // 仅作为 M3 fallback
val Pink40 = Color(0xFF7D5260)           // 仅作为 M3 fallback
```

6 个 M3 默认色 — 全部仅作为 fallback 出现在 `Theme.kt`，**实际 UI 中 0 次使用**（grep 验证）。

### 2.2 主题（Theme.kt）

```kotlin
@Composable
fun My_knowledgeTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    dynamicColor: Boolean = true,    // 默认 true
    content: @Composable () -> Unit
)
```

- `dynamicColor = true` 默认 → Android 12+ 设备上 `dynamicLight/DarkColorScheme(context)` 接管颜色，**所有硬编码 `Color(0xFF147EC5)` 仍按硬编码渲染**（因为它们不通过 `MaterialTheme.colorScheme.primary`），结果是 **Ocean 蓝色 + 壁纸色调和 primary 混在一起**。
- 没有任何自定义 dark color scheme。
- `MaterialTheme(colorScheme = ...)` 之外没有任何 `CompositionLocal` 提供 design token。

### 2.3 字体（Type.kt）

```kotlin
val Typography = Typography(
    bodyLarge = TextStyle(
        fontFamily = FontFamily.Default,  // Roboto / 系统默认
        fontWeight = FontWeight.Normal,
        fontSize = 16.sp,
        lineHeight = 24.sp,
        letterSpacing = 0.5.sp
    )
)
```

- 13 个 M3 typography token 中只定义了 1 个。
- `FontFamily.Default` = Roboto / 系统默认（没有选择品牌字体）。

## 3. 资源层

### 3.1 颜色资源（`res/values/colors.xml`）

```xml
<color name="purple_200">#FFBB86FC</color>
<color name="purple_500">#FF6200EE</color>

<color name="teal_200">#FF03DAC5</color>
<color name="teal_700">#FF018786</color>
<color name="black">#FF000000</color>
<color name="white">#FFFFFFFF</color>
```

7 个色值，**全部是 Android Studio 新建项目的默认 MDC 调色板**（Material 1 时代），与 Compose 层 `Color.kt` 没有任何关联。

### 3.2 字符串资源（`res/values/strings.xml`）

```xml
<resources>
    <string name="app_name">my-knowledge</string>
</resources>
```

1 条 `<string>` 标签。所有 23 个屏幕的 **594 个中文字符串直接写在 Composable 内**（grep 验证）。
i18n 不可行；任何文案变更都要全局 grep。

### 3.3 主题 XML（`res/values/themes.xml`）

```xml
<style name="Theme.My_knowledge" parent="android:Theme.Material.Light.NoActionBar" />
```

引用的是 `android:Theme.Material`（MDC 1），不是 Material Components 或 Material 3。
整个 XML 主题层没有真正定制任何属性。

## 5. 图标系统

- **Material Icons Extended** 大量使用（29 × `Icons.AutoMirrored.Filled.*`、12 × `Icons.Default.Delete`、9 × `Icons.Default.Check`、6 × `Icons.Default.Hub`、6 × `Icons.Default.BubbleChart` ...）。
- **Unicode 字形 fallback**：`KnowledgeComponents.kt:60-70` 用 `⌘` / `▦` 充当 icon text（"知识脉络" / "碎片整理" 卡片），无视觉等价性。
- **没有 Iconify / Lucide 等自定义图标库**。
